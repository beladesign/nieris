NIERIS — ESTRUTURA CORRIGIDA

Agora NÃO existe Jekyll nem permalink.

Na raiz do repositório devem existir apenas:

.github/
  workflows/
    pages.yml

nieris-site/
  index.html
  lore.html
  music.html
  credits.html
  fanarts.html
  nabis.html
  moderation.html
  socials.html
  styles.css
  script.js
  assets/

COMO O DEPLOY FUNCIONA

Você edita/substitui somente a pasta nieris-site.

O workflow monta automaticamente a publicação assim:

nieris-site/lore.html       -> /lore/
nieris-site/music.html      -> /music/
nieris-site/credits.html    -> /credits/
nieris-site/fanarts.html    -> /fanarts/
nieris-site/nabis.html      -> /nabis/
nieris-site/moderation.html -> /moderation/
nieris-site/socials.html    -> /socials/

A Home continua em /.

IMPORTANTE

No GitHub:
Settings > Pages > Source = GitHub Actions

Para atualizar depois:
1. apague somente a pasta nieris-site antiga;
2. envie a nova pasta nieris-site;
3. faça commit.

Não apague .github.
